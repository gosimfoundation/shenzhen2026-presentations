# GOSIM Shenzhen 2026 Presentations

[English](#english) · [中文](#中文)

## English

This repository collects presentation slides and supporting materials from GOSIM Shenzhen 2026, organized by track and date. PDFs, PowerPoint files, videos, and other materials are stored directly in the repository folders and updated as they become available.

### Download materials

**Download the latest materials directly from the folders on the `main` branch. Older Release archives are outdated; please do not use them.**

- **[GitHub repository](https://github.com/gosimfoundation/shenzhen2026-presentations)**: open the **Code** tab, select the `main` branch, then click the **Code → Download ZIP** menu, or [download the latest `main` ZIP directly](https://github.com/gosimfoundation/shenzhen2026-presentations/archive/refs/heads/main.zip).
- **For downloads in China, use the [GitCode repository](https://gitcode.com/gosimfoundation/shenzhen2026)**: open the **Code** tab, select the `main` branch, then use the **ZIP** menu above the file list to download the latest repository archive.
- To download an individual presentation, browse to its track and date folder, open the file, and use the file's download option.

Extract the ZIP archive to access the presentation folders and files.

The `main` branches of both repositories are kept in sync and contain the same presentation files. Each platform generates its ZIP archive from the current branch contents. Download it again to get the latest additions and removals.

### Usage

Materials are provided as collected. Rights remain with the respective speakers or rights holders. Please follow any notices in the files or contact the rights holders before reuse or redistribution.

## 中文

这里收录 GOSIM 深圳 2026 的演讲幻灯片及辅助资料，按分会场和日期整理。PDF、PPTX、视频等文件直接保存在仓库文件夹中，随资料收集持续更新。

### 下载资料

**请直接下载 `main` 分支文件夹中的最新资料。旧 Release（发行版）压缩包中的文件已过时，请勿使用。**

- **国内下载：[GitCode 仓库](https://gitcode.com/gosimfoundation/shenzhen2026)**：进入 **Code（代码）** 页面，确认分支为 `main`，使用文件列表上方的 **ZIP** 菜单下载最新仓库压缩包。
- **[GitHub 仓库](https://github.com/gosimfoundation/shenzhen2026-presentations)**：进入 **Code** 页面，确认分支为 `main`，点击绿色 **Code → Download ZIP**，也可以[直接下载最新 `main` 分支 ZIP](https://github.com/gosimfoundation/shenzhen2026-presentations/archive/refs/heads/main.zip)。
- 只需要某一份演讲资料时，可以进入对应的分会场和日期文件夹，打开文件后单独下载。

下载 ZIP 后解压，即可获取各分会场和日期文件夹中的演讲资料。

两个仓库的 `main` 分支同步维护，提供相同的演讲文件。ZIP 压缩包由平台按当前分支内容生成；新增或移除资料后，重新下载即可获取最新版本。
